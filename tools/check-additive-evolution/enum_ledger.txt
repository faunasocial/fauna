# enum_ledger — the answer `transport.md` § Schema and forward-compat
# discipline, rule 3 gives every serde-deserializable enum in our own Rust
# (`libs/fauna-*`, `bins/`, the Rust apps). Owner of the rule, the scope and
# the meaning of each answer: that section's "Rule 3 in full".
#
# One entry per line: `<answer> <key>`, then `#` and the reason.
#   key    = `<crate>::<module path>::<Enum>` (the file's path under `src/`,
#            `lib`/`mod`/`main` dropped, then any inline `mod`; an enum
#            declared inside a function keys at its enclosing module), or
#            `<crate>::*` (`local` only) for a crate whose enums ALL never
#            cross a release boundary. A crate that holds any enum on the
#            wire, at rest or on the IPC lists every enum it has.
#            `#[cfg(test)]` enums and modules are never scanned and never
#            listed.
# `tools/check-additive-evolution` holds this file (owner of the rules:
# transport.md, "The ledger and the gate"): an unlisted enum, a line naming no
# enum, an `open` enum with no arm, or a malformed line is red; a removed
# variant needs a `ratified-breaks.txt` line; a variant added to a
# closed-consensus/ladder/extension/fixed enum needs this line changed in the
# same change. `--no-owed` fails on any `owed-` line.
#   answer = open            an unknown arm exists
#          | owed-carry      ruled open, the arm keeps what it could not read
#                            (always the form for an enum with data variants);
#                            NOT BUILT YET
#          | owed-collapse   ruled open, a lossy `#[serde(other)]` unit arm
#                            that is never written back; NOT BUILT YET
#          | skip            covered by record-level skip in its reader loop
#          | owed-skip       ruled skip; the loop's behaviour is not yet
#                            built or not yet pinned by a test
#          | closed-request | closed-consensus | closed-ladder
#          | closed-extension | closed-fixed
#                            closed by design, on the named ground
#          | locked          a version-locked hop: both ends ship together
#          | local           never crosses a release boundary
#          | foreign         a foreign protocol's shape
# An `owed-` line is a debt: `--no-owed` refuses any, and none may land on main.
# A row that builds an arm rewrites its line to `open` (or `skip`) in the same
# commit. Closing an enum, or adding a variant to a closed one, is an edit to
# this file that names the reason.
