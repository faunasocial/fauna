# fauna-android — the Android app

Native Android app in Kotlin + Jetpack Compose, consuming the shared Rust
core via UniFFI (`libs/fauna-ffi`, built for all four Android ABIs).

## Build

Environment setup (JDK 17, Android SDK, NDK toolchain — including the
extra steps for ARM64 hosts): **[BUILD-SETUP.md](BUILD-SETUP.md)**.

Then, from the repository root:

```sh
just android-debug      # Rust FFI for all ABIs + Kotlin bindings + debug APK
just android-release    # release APK
```

## Test

```sh
apps/fauna-android/gradlew -p apps/fauna-android test    # JVM unit tests (Robolectric FFI tests need a host libfauna_ffi.so — see BUILD-SETUP.md)
```

Instrumented/e2e tests run on an emulator via the cross-app suite
(`tests/e2e-unified/README.md`).

## Layout

- `app/src/main/java/com/fauna/app/ui/screen/` — one package per page (feed, conversations, settings, admin, onboarding, …)
- `app/src/main/java/com/fauna/app/ui/viewmodel/` — view-models over the shared machines
- Generated Kotlin FFI bindings land under the `com.fauna.ffi` package (regenerated by `just android-ffi`)

UI element IDs come from `tests/e2e-unified/ui.yaml` (`Modifier.testTag`) —
the same IDs as every other app.
