# What works where

Fauna is one app on seven platforms and one small server. This page shows, feature by
feature, what has been proven to work on each of them.

Every mark comes out of an actual test run: the run writes down what it saw, and this
page is generated from that record. We would rather show you gaps than green ticks we
cannot back up.

A feature that the server alone provides is tested on the server, not through an app,
so it shows the same mark under every app.
