# What works where

Fauna is one app on seven platforms and one small server. This page says, feature by
feature, what has been proven to work on each of them — and it is not a promise page.
Every mark below comes out of an actual test run: the run writes down what it saw, and
this page is generated from that record.

That means it can tell you three different things, and the difference matters.
A **✅** is a feature whose whole set of tests passed on that app. A **⚠** is a partial
result: some passed, some did not, or the feature is only partly covered by tests so
far. A **❌** means tests exist and none of them passed. A **blank** is the honest one —
it says *no run has been recorded yet*, which is a statement about our records and not
about the software; the feature may work perfectly and simply not have been re-tested
on that platform since we started keeping this record. A **—** is different again: it
means the feature is deliberately absent there, because the platform has no such thing.

We would rather show you a page with blanks in it than a page of green ticks we cannot
back up.
