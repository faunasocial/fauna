# The Versions page — public summary

> The full document describes part of the maintainers' private development
> setup and is not published. Other documents in `docs/goal/` that reference
> `fleet-versions.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers'
private console has one page that shows what each release took to publish —
its wall clock, its processor time and model tokens, the steps that had to be
run again and why — and how that changes from release to release. The page
and the records behind it are private infrastructure and out of scope for
this repository; what a release must prove before it is published is
summarized in [`release-attempt.md`](release-attempt.md), and the table of
released builds is [`release-table.md`](release-table.md).
