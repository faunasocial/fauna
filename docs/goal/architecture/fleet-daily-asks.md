# The daily asks — public summary

> The full document describes part of the maintainers' private development
> setup and is not published. Other documents in `docs/goal/` that reference
> `fleet-daily-asks.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers run their
development sessions as a fleet, and some questions in its work queue can be
answered only by the project's owner. A small part of that fleet gathers those
questions, ranks them by how much work each answer unblocks, and shows the
owner a few a day, each as a short list of concrete steps. Changes the
project's goal documents already settle are shown to the owner as declarations
they may veto within a window, rather than as questions. How the questions are
chosen and presented is private infrastructure and out of scope for this
repository; the service it is part of is summarized in
[`fleet-janitor.md`](fleet-janitor.md).
