# The row's resources — public summary

> The full document describes part of the maintainers' private development
> setup and is not published. Other documents in `docs/goal/` that reference
> `fleet-row-resources.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers run their
development sessions as a fleet across several machines and keep a private
record of what each task of their work queue cost: wall clock, processor time
and model tokens. How that record is measured, kept and shown is private
infrastructure and out of scope for this repository; the token ledger it
builds on is summarized in [`fleet-tokens.md`](fleet-tokens.md).
