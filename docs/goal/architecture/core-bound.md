# The core bound — public summary

## What a contributor needs to know

Nothing in this repository requires any of it. A plain `cargo build` of the
crate you change is the supported path, and it uses whatever cores your machine
has. How the maintainers' own machines ration their work is private
infrastructure and out of scope for this repository.
