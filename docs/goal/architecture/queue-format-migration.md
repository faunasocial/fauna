# The queue format's migrations — public summary

> The full document describes how the maintainers' private work-queue files
> change shape between tooling versions, and is not published. Other documents
> in `docs/goal/` that reference `queue-format-migration.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers schedule their
own work from private queue files that are not part of this repository; how
those files are migrated from one shape to the next is private infrastructure
and out of scope here. See [`task-files.md`](task-files.md) for the summary of
those queue files.
