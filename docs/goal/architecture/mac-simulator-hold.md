# macOS's simulator hold — public summary

> The full document describes part of the maintainers' private development
> setup and is not published. Other documents in `docs/goal/` that reference
> `mac-simulator-hold.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. Running the iOS end-to-end
tests on your own machine boots the simulator the ordinary way, at whatever
width your machine allows. How the maintainers' own machines hold the
simulator inside their CPU budget is private infrastructure and out of scope
for this repository; the machine-wide picture is summarized in
[`mac-core-hold.md`](mac-core-hold.md).
