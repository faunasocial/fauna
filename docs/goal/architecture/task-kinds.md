# NEXT-file row kinds — public summary

> The full document describes the states an item in the maintainers' private
> work queues can be in, and is not published. Other documents in `docs/goal/`
> that reference `task-kinds.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers schedule their
own work from private queue files that are not part of this repository; the
states an item in them can take are private infrastructure and out of scope
here. See [`task-files.md`](task-files.md) for the summary of those queue
files.
