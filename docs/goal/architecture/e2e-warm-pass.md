# The warm pass — public summary

> The full document describes part of the maintainers' private development
> setup and is not published. Other documents in `docs/goal/` that reference

## What a contributor needs to know

Nothing in this repository requires any of it. Running an end-to-end test on
your own machine builds whatever the test needs the ordinary way, before the
test starts. How the maintainers' own machines schedule those builds around
their shared test lanes is private infrastructure and out of scope for this
repository; the machine-wide picture is summarized in
[`build-slot-pool.md`](build-slot-pool.md).
