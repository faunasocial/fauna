# Pool selection — public summary

> The full document describes how the maintainers' private work queues hand
> rows to their own idle development checkouts, and is not published. Other
> documents in `docs/goal/` that reference `pool-selection.md` resolve here.

## What a contributor needs to know

Nothing in this repository requires any of it. The maintainers schedule their
own work from private queue files that are not part of this repository; how a
checkout picks its next item from them is private infrastructure and out of
scope here. See [`next-files.md`](next-files.md) for the summary of those
queue files.
