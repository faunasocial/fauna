Fauna

This installer sets up Fauna on your Mac. Choose which components to install on the next screen:

  • Fauna Desktop App — the native macOS client (selected by default)
  • Sync Service — background file sync (selected by default)
  • Nest Service — self-host your own Fauna server
  • Bridge Service — IMAP/CalDAV for standard mail & calendar apps

The most common setup is just the app and sync, connecting to a remote nest. Tick Nest Service to run your own server on this Mac. A selected server component starts automatically after install.

The app installs to /Applications; services install to /usr/local/bin/. Run sudo fauna-uninstall to remove everything.
