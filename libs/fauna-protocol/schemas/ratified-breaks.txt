# ratified-breaks — the user-ratified in-place wire breaks the two
# additive-evolution gates accept (`scripts/check-cddl-evolution.py`, cheap
# tier, and `tools/check-additive-evolution`, CHECK tier). Both gates block
# every removed / renamed / retyped / optional→required field by default
# (`docs/goal/architecture/version-compatibility.md` I4); an entry here is
# the ONLY way past them, and it exists because a ratified in-place break
# (§ Dimension 2's write-offs) must not red the async merge-gate check on
# every pass until the last-green tip moves — which it cannot while red.
#
# One entry per line, whitespace-separated:
#   <gate> <key> <transition> <ratified-on> <ratification>
#   gate = `cddl` (key: `Type` or `Type.field` in libs/fauna-protocol/schemas)
#        | `rust` (key: `module::Struct.field`, the tool's module-qualified
#          struct key plus the WIRE field name; or, for an enum the tool
#          holds against tools/check-additive-evolution/enum_ledger.txt,
#          `<crate>::<module>::<Enum>::<Variant>` — the ledger's key plus
#          the variant's WIRE name, no `.`, transition `removed` only)
#   transition = `removed` | `optional→required` | `retyped→<Type>` (a bare
#          cddl `Type` is only ever `removed`; `<Type>` is the gate's own
#          whitespace-free rendering of the NEW type)
# An entry excuses ONLY the finding of its own transition on its own key:
# an `optional→required` entry excuses the tightening and never a later
# removal or retype of the field (once the tightening is in the base there
# is nothing left for it to excuse); a `Type removed` entry excuses the
# type's removal and no field edit of a same-named type; a `retyped→<Type>`
# entry excuses a retype TO `<Type>` and no other, so a later retype away
# from it is a fresh finding. A line whose gate token is neither `cddl` nor `rust` fails BOTH
# gates (exit 2); a line naming a real token but otherwise malformed (too
# few fields, an unratifiable transition, a bare type tightened) fails only
# that token's OWN gate (exit 2) — the sibling gate skips a line it doesn't
# own without validating it.
# `#` starts a comment. Entries are permanent: a removed name never comes
# back — both gates refuse a head that revives a `removed` key, and each
# gate independently refuses a head whose own-gate entries drop one the
# merge base carried, catching a deletion even without a revival — so
# nothing ever needs to leave this list. Who writes a line is owned by
# version-compatibility.md § Dimension 2, the fourth exception's "Who writes a
# ledger line" rule (user-ruled 2026-09-30): a sweep-class remnant line — the
# entry cites the sweep, every current writer verified to always send the
# value — is transcribed in the commit carrying the removal; any other break
# (a live kind retired by a cutover, a retype, any break from the 2026-10
# baseline on) is a maintainer ruling. Grammar owner:
# docs/goal/architecture/transport.md § Schema and forward-compat discipline.
